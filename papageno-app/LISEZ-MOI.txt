PAPAGENO · L'APPLICATION MOBILE (version 13)
============================================

Ce dossier contient l'application mobile de Papageno.
C'est une « application web installable » (PWA) : on l'installe depuis le site,
sans passer par un store, sur iPhone comme sur Android.

Une fois installée, Papageno :
- a sa propre icône sur l'écran d'accueil (la tortue) ;
- s'ouvre en plein écran, comme une vraie appli ;
- reste ouverte même sans réseau (la boutique, le bocal, la radio « Musique douce » et « La mer »,
  les voix d'accueil et d'au revoir). La « Playlist 1 » se joue avec une connexion internet.

1. METTRE LE DOSSIER EN LIGNE (gratuit)
---------------------------------------
Conseillé : Cloudflare Pages (gratuit, bande passante illimitée : la musique ne coûte rien).
  1. Créer un compte gratuit sur https://dash.cloudflare.com/sign-up
  2. Menu « Workers & Pages », puis « Create application », « Get started »,
     puis « Drag and drop your files ».
  3. Donner un nom au projet (par exemple papageno-test) : ce sera l'adresse
     https://papageno-test.pages.dev
  4. Glisser le fichier papageno-app.zip (ou le dossier « papageno-app »), puis « Deploy site ».
  Limites gratuites : 1 000 fichiers et 25 Mo par fichier (l'appli : 35 fichiers, 5 Mo au plus).
  Nouvelle version : ouvrir le projet, « Create a new deployment », glisser le nouveau dossier.

Autre possibilité : Netlify Drop (https://app.netlify.com/drop), glisser-déposer le dossier.
  Attention : l'offre gratuite donne 300 crédits par mois ; chaque mise en ligne en coûte 15
  et chaque Go envoyé aux visiteurs en coûte 20. Quand les crédits sont épuisés, le site est
  mis en pause jusqu'au mois suivant. Pour un site avec 45 minutes de musique, Cloudflare est plus sûr.

Le site est en « https » tout seul (obligatoire pour installer l'appli).
On peut brancher plus tard son propre nom de domaine (une dizaine d'euros par an).


2. INSTALLER L'APPLI SUR SON TÉLÉPHONE
---------------------------------------
Android (Chrome) :
  ouvrir le site, puis toucher le bouton « Installer l'appli Papageno »
  sous « Entrer dans la boutique ».
  (Ou : menu ⋮ de Chrome, puis « Installer l'application ».)

iPhone (Safari) :
  ouvrir le site, toucher « Partager » (le carré avec une flèche),
  puis « Sur l'écran d'accueil ». Le site affiche aussi cette aide.


3. PUBLIER SUR LES STORES (facultatif, plus tard)
-------------------------------------------------
Le même site peut être emballé pour Google Play et l'App Store avec PWABuilder
(https://www.pwabuilder.com), un outil gratuit de Microsoft : on lui donne
l'adresse du site en ligne, il prépare les paquets pour les stores.

Il faut des comptes développeur :
- Google Play : 25 $, payés une seule fois ;
- App Store (Apple) : 99 $ par an. Pour Apple, la dernière étape se fait sur un Mac (Xcode).


4. METTRE À JOUR L'APPLI
------------------------
Quand le site change : remplacer les fichiers en ligne, puis ouvrir « sw.js »
et changer la ligne VERSION (cette version est papageno-v10 ; la prochaine sera papageno-v11).
Les téléphones récupèrent alors la nouvelle version à leur prochaine visite.


5. À SAVOIR AVANT D'ACCUEILLIR DU PUBLIC
--------------------------------------
Pour l'instant, comme le prototype, l'appli garde les données sur chaque téléphone.
La base de données partagée (Supabase est prévue dans le code) est l'étape suivante. Elle permettra :
- que les tickets et la monnaie rendue passent vraiment d'un visiteur à l'autre ;
- de compter les vraies personnes en caisse (10 par caisse, une nouvelle caisse à la 11e) ;
- d'ouvrir son porte-monnaie avec son code sur n'importe quel téléphone ;
- de prévenir l'organisatrice des tickets à relire et des demandes d'effacement.


6. ACCESSIBILITÉ
----------------
L'appli et le site partagent le même code : ils ont les mêmes réglages d'accessibilité.
- Personnes sourdes ou malentendantes : tout ce que disent les voix est aussi écrit à l'écran,
  aucun son n'est indispensable, et le « SMS 114 » (urgence par écrit) est visible partout
  à côté du 3114.
- Personnes malvoyantes : la page est déclarée en français pour les lecteurs d'écran
  (VoiceOver, TalkBack), chaque bouton a un nom, les textes sont assez contrastés,
  l'anneau de focus se voit sur tous les fonds, et l'affichage tient sans défilement
  horizontal jusqu'à 320 pixels de large (zoom à 400 %).
- Tout se fait au clavier ; sur ordinateur, les flèches passent d'un rayon à l'autre ;
  sur téléphone, la feuille « Plus » garde le clavier tant qu'elle est ouverte et se ferme avec Échap.
- Les animations suivent le réglage « réduire les animations » du téléphone.
Vérifié avec axe-core (règles WCAG 2.2, niveaux A et AA) sur 14 écrans, sur téléphone et sur ordinateur : aucune erreur.
Ces tests automatiques ne remplacent pas un essai avec de vraies personnes
qui utilisent un lecteur d'écran ou qui sont sourdes.
